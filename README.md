# 百果集

百果集是一个水果店微信小程序演示项目，使用原生 TypeScript、WXML 和 WXSS 编写。包含顾客购物小程序、云函数源码和独立的商家网页后台。当前订单、支付和后台管理以本地演示为主，不接真实支付；云函数尚未部署到微信云环境。

## 项目功能

- 顾客端：水果分类与商品、固定规格、购物车、配送或自提、模拟支付、订单查询和地址管理。
- 云函数源码：商品、门店、购物车、地址、报价、订单及库存逻辑；需要单独配置 CloudBase 环境后部署。
- 商家后台：商品与分类、规格库存、订单查询及完成、门店信息编辑。首版数据保存在当前浏览器的 IndexedDB。
- 不包含会员营销、在线收款、配送轨迹或骑手派单。

## 启动

需要 Node.js 20 或更高版本。

```powershell
npm ci
npm run build:npm
npm run check
```

然后用微信开发者工具导入项目根目录并编译小程序。微信工具使用项目配置中的 AppID 和基础库版本。不要提交本机 `project.private.config.json`。

### 商家网页后台

后台位于 `admin`，依赖和构建独立于小程序：

```powershell
cd admin
npm ci
npm run dev
```

打开 <http://localhost:5173/>。演示账号为 `admin`，密码为 `demo123456`。也可访问 [Netlify 演示站点](https://baiguoji-admin.netlify.app/)；该站点目前开启了 Netlify 团队登录保护。页面内的演示账号只用于体验后台流程，不是生产管理员身份认证。

商品素材已在 `miniprogram/assets/fruit-catalog.jpg`，不依赖外部商品图片。图标使用 TDesign Icon。

## 演示路径

- 首页选商品 → 选择规格 → 加购物车 → 结算。
- 配送：先添加完整地址；自提：填写联系人与 11 位手机号。
- 提交订单后选择“模拟支付成功”“模拟支付失败”或“暂不支付”。不会真实扣款。
- 我的 → 我的订单：查看订单、继续支付或取消待支付订单。
- 我的 → 演示工具：模拟配送完成/顾客取货，或确认后重置本小程序演示数据。
- 支付成功仅表示模拟结果；没有真实配送、付款、退款或微信登录。

默认配送费 ¥6，自提免费，库存按 SKU 管理。提交订单预占库存，取消待支付订单释放库存；未支付订单不会自动过期。地址、购物车、订单存储在当前设备 `fruitshop:v1` 中。

## 门店配置

店名已设为“百果集”。在 `miniprogram/config/shop.ts` 配置门店地址、电话、营业时间、配送费及配送说明。未配置电话时不拨号。商品在 `miniprogram/data/products.ts`，图片为 AI 生成演示素材，产地及文案在营业前须由店家核实。

后台使用自己的浏览器 IndexedDB，首次生成五笔示例订单，刷新或退出后不重置业务数据。它不读取设备中的小程序订单，后台修改暂不影响小程序，也不写入云端。localhost 与 Netlify 站点的数据相互独立。完整使用说明见 [后台 README](admin/README.md)。

## 结构

- `miniprogram/core`：纯 TypeScript 金额、库存、地址和订单规则。
- `miniprogram/services/shop.ts`：异步服务门面及本地持久化，后续替换为请求后端。
- `miniprogram/pages`：首页、购物车、我的。
- `miniprogram/shop`：详情、结算、订单、地址及演示工具分包。
- `cloudfunctions/shop-api`：云函数业务、CloudBase 数据库适配及独立依赖锁文件。
- `cloudfunctions/seed-data.cjs`：约 12 款商品、24 个 SKU、分类及门店初始数据定义；只输出数据，不连接云环境。
- `admin`：独立网页商家后台、本地持久化服务与测试；不参与小程序构建。
- `tests`：核心业务和持久化回滚测试。

默认模板 logs 页面保留在目录中但不注册，不批量删除模板文件。

## 后端接入

见 [接口说明](docs/interfaces.md)。真实后端必须以服务端价格和库存为准，实现微信身份鉴别、订单归属校验、支付回调验签及幂等，不允许客户端直接设定已付款/已完成。上线前移除模拟支付与演示工具入口。

### 云函数源码阶段

当前没有正式 AppID 或可用云环境，保留现有项目配置和本地服务。云函数提供商品、分类、门店信息、云端购物车与地址、服务端报价、事务下单、库存预占与取消释放、用户订单查询。模拟支付和模拟完成只在 `APP_STAGE=development` 且 `ENABLE_DEMO_ACTIONS=true` 时可用，默认关闭。真实支付、云端部署、顾客端接入和生产店家权限暂缓。

在项目根目录运行 `npm run test:cloud` 可独立测试云函数，不需要云端凭证或安装云函数依赖。需要验证 SDK 或以后部署时，在 `cloudfunctions/shop-api` 执行 `npm ci --ignore-scripts`，使用独立锁文件安装；不要把这套服务端依赖构建进小程序。

取得正式 AppID 后，按 [云后台配置与部署步骤](docs/interfaces.md#云后台配置与部署步骤) 确认环境、创建集合与索引、配置安全规则、导入初始数据并部署。初始数据只能导入新的空集合，不覆盖已有库存或订单；不迁移设备中现有演示数据。
